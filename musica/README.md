# Músicas — meu ardio

Coloca aqui os ficheiros de áudio (`.mp3`) das músicas da playlist.

Sugestão de nomes simples e sem espaços/acentos, ex:
- `01-paris.mp3`
- `02-weightless.mp3`

Depois de adicionares, dá-me o nome de cada ficheiro + o nome da música a mostrar,
e eu ligo cada faixa ao player na página `/lair`.

No site ficam acessíveis em `/musica/<ficheiro>.mp3`.
